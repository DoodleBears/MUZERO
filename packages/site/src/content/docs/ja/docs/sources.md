MUZERO は音楽を 3 つの場所から集めます：アップロードしたファイル、検索したオンラインソース、AI DJ が生成した曲。すべて同じローカルライブラリに入ります。

## 自分のものをアップロード

- **音声ファイル、フォルダ、MV** を取り込む——混在セットに入ります（ひとつのセットに音声と動画を同居可）。
- どの曲にも**メモ・タグ・思い出の写真・カスタムカバー**を追加。
- タイトル・アーティスト・アルバム・タグ・メモ・歌詞・表記ゆれ・ソースメタデータで検索。
- アーティスト・アルバム・セット・思い出・歌詞・再生履歴を同じローカルライブラリで。

メディアの bytes は内容アドレスで保存され、軽量な track 行とは別になっているため、大きなライブラリでも高速かつ検索可能です。

## オンラインソース（デスクトップ）

次のソースのストリームを検索・解決：

- **NetEase Cloud Music**
- **Bilibili**
- **YouTube**

ヒント：

- `⌘F` 検索にリンク——または **BV 番号 / 動画 ID / プレイリストのリンク**——を貼ると、キーワード検索ではなく直接解決します。
- ソースが必要とする場合、**ローカルログイン**で高音質やアカウント限定コンテンツを利用できます。ログインは端末内に保存（[BYOK](/ja/docs/agent-dj/#byok)）。
- ストリーミング曲とカバーは**ローカルにキャッシュ**してオフライン再生できます。
- デスクトップでは Bilibili / YouTube の動画を再生可能なローカル曲として**ダウンロード**（画質選択可）、お気に入り / プレイリストをまるごとセットとして取り込めます。

> オンラインソースは**デスクトップ版**が最適です——一部のソースが必要とするカスタムリクエストヘッダーを送れます。Web 版は CORS の制約を受ける場合があります。
