MUZERO はホスト型の **Web 版**と **デスクトップ版**（Electron）があります。ライブラリは端末内のデータベースに保存されます——アカウントも MUZERO メディアバックエンドもありません。

## アプリを開く

- **Web** —— [my.mu0.app](https://my.mu0.app) を開いてアップロードを始める。
- **デスクトップ** —— [ダウンロードページ](/ja/download/)からインストーラーを入手。オンラインソース対応はデスクトップ版が最も充実しています（一部のソースが必要とするリクエストヘッダーを設定できます）。

Web 版とデスクトップ版はそれぞれ別のローカルライブラリを持ちます（origin が異なるため）。[クラウド同期](/ja/docs/sync/)でひとつのライブラリを共有できます。

## 最初の 5 分

1. **音楽を追加。** 音声ファイル、フォルダ、MV をドラッグ——またはリンクを貼る（[ソース](/ja/docs/sources/)参照）。
2. **メモを添える。** タグ、メモ、思い出の写真、カスタムカバーを。「曲は思い出を運ぶ」がすべて。
3. **検索。** `⌘F` / `Ctrl+F` でタイトル・アーティスト・タグ・歌詞・メモ・オンラインソースを横断検索。
4. **セットを作る。** 曲をセット（プレイリスト）にまとめる。アップロードと AI 生成曲を混在できます。
5. **DJ に任せる**（任意）。モデルをつなぎ、[Agent DJ](/ja/docs/agent-dj/) にキューを続けさせる。

## キーボード中心

MUZERO は大規模ローカルライブラリとキーボード操作のために設計されています：

- 再生・キュー・検索・ナビゲーション・ライブラリ操作のショートカットをカスタマイズ。
- `⌘F` / `Ctrl+F` でどこからでもグローバル検索。
- 6,000 曲のライブラリも、待たされず即使えるべきです。
