Agent DJ は LLM をあなたのライブラリの司書・キュレーター・音楽生成オーケストレーターに変えます。MUZERO をサブモニターに置けば、コーディング・デザイン・執筆・長い集中セッションのあいだ、ラジオのように働きます。

## できること

- **検索とキュレーション** —— Agent はライブラリを検索し、タグやメモを文脈に使い、セットを作ったり続けたりします。
- **リクエスト対応** —— ムードを伝え、seed のセットを渡せば、プレーヤーを見張らずにキューを続けます。
- **生成** —— 新しい曲が欲しいとき、DJ は `TrackBrief`（caption、歌詞、style、BPM、key、structure、生成ヒント）を書き、音楽生成 provider に渡します。

## Provider

音楽生成は差し替え可能です：

- **Mock** —— オフラインのプレースホルダー provider（既定）。ネットワークや key なしでもループが回ります。
- **Cloud（BYOK）** —— あなたが設定する実際の生成 API。DJ は特定の vendor に直接話しません。adapter が brief を翻訳するので、ライブラリは一社に依存しません。

## BYOK

LLM と音楽生成の API key は**自分で持ち込む鍵**です：設定で入力し、端末内にのみ保存されます。MUZERO はサーバー側に key を持たず、あなたが設定した第三者 API 以外への送信はありません。

> key はアプリ bundle、コミットした `.env`、URL、ログ、テレメトリには決して書き込みません。
