MUZERO はライブラリをホストしません。クラウド同期は**あなたが設定・所有するストレージ**を指すので、メディアを誰かに預けずに、すべての端末を同じライブラリにできます。

## 仕組み

1. 設定で**クラウドドライブを一度設定**（現在のパスは Cloudflare R2 / S3 互換オブジェクトストレージ）。
2. MUZERO はライブラリをそのストレージに **publish** し、更新を **pull** します。
3. 信頼できる**セットアップリンク**をコピーして、別のスマホや PC を同じライブラリにすばやく接続。

同期される内容：セット、曲、カバー、メモ、思い出、歌詞、再生メタデータ——すべて自分の端末間で、間に MUZERO サーバーはありません。

## ストレージバックエンド

- **現在**：Cloudflare R2 / S3 互換オブジェクトストレージ。
- **ロードマップ**：Nextcloud、Synology、rclone serve などに向けた WebDAV 対応。

メディアの bytes は内容アドレスで保存されるので、再同期は変化した分だけ移動します。

## 友だちと共有

- 読み取り専用のライブラリ / 共有リンクで音楽を渡せます。
- より豊かな `mu0.app` 短縮リンクと取り消し可能な招待はロードマップに。その場合でも、**曲の bytes は設定したストレージや端末から**取得され、`mu0` サービスが必要なのは共有リンクと権限メタデータだけです。

## 資格情報はローカルに

ストレージの資格情報は端末内にのみ保存されます（BYOK）。アプリ bundle、コミットした `.env`、URL、ログ、テレメトリには決して書き込みません。
