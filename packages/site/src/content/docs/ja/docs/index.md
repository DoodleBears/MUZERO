MUZERO は「曲は思い出でもある」人のための**ローカルファーストの音楽・ビデオプレーヤー**です。自分だけのライブラリ、散らばったオンラインソース、ビジュアル再生、自分のクラウド同期、LLM で動く DJ をひとつのアプリにまとめます。

## 4 つの体験、ひとつのライブラリ

- **プライベート音楽ミュージアム** —— 音声や MV を取り込み、曲ごとにメモ・タグ・カバー写真を添え、その曲が属する時間へ戻る。
- **マルチソースハブ** —— デスクトップで NetEase Cloud Music、Bilibili、YouTube を検索・再生し、MUZERO に保持。
- **ビジュアルプレーヤー** —— Poweramp に着想を得た UI、カバー由来の色、リアクティブ背景、音声ビジュアライザー。
- **Agent DJ** —— モデルをつなぎ、ライブラリ検索、セットのキュレーション、リクエスト対応、次の曲の生成を任せる。

## 約束

| 原則 | 意味 |
|------|------|
| **ローカルファースト** | 曲、セット、メモ、タグ、カバー、設定、再生統計は端末内 DB `muzero-db` に。 |
| **MUZERO はメディアを預からない** | MUZERO はライブラリをホストしません。クラウド同期はあなたが設定・所有するストレージを指します。 |
| **BYOK** | LLM key、音楽生成 key、ソースのログイン、クラウド資格情報は端末内に保存。 |
| **無料の hosted service** | [mu0.app](https://mu0.app) は配布・Web アクセス・任意の共有リンクのためで、ライブラリを預かりません。 |
