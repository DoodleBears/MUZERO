MUZERO는 노래가 곧 추억인 사람들을 위한 **로컬 우선 음악·비디오 플레이어**입니다. 개인 라이브러리, 흩어진 온라인 소스, 비주얼 재생, 내 클라우드 동기화, LLM 기반 DJ를 하나의 앱으로 묶습니다.

## 네 가지 경험, 하나의 라이브러리

- **개인 음악 박물관** — 오디오와 MV를 업로드하고, 곡마다 메모·태그·커버 사진을 더해 그 곡이 속한 시간으로 돌아갑니다.
- **멀티 소스 허브** — 데스크톱에서 NetEase Cloud Music, Bilibili, YouTube를 검색·재생하고 MUZERO에 보관합니다.
- **비주얼 플레이어** — Poweramp에서 영감을 받은 UI, 커버 기반 색상, 반응형 배경, 오디오 비주얼라이저.
- **Agent DJ** — 모델을 연결해 라이브러리 검색, 세트 큐레이션, 신청 받기, 다음 곡 생성을 맡깁니다.

## 약속

| 원칙 | 의미 |
|------|------|
| **로컬 우선** | 곡, 세트, 메모, 태그, 커버, 설정, 재생 통계는 기기 로컬 DB `muzero-db`에 저장됩니다. |
| **MUZERO는 미디어를 호스팅하지 않음** | MUZERO는 라이브러리를 보관하지 않습니다. 클라우드 동기화는 사용자가 설정·소유한 스토리지를 가리킵니다. |
| **BYOK** | LLM key, 음악 생성 key, 소스 로그인, 클라우드 자격 증명은 기기에 로컬 저장됩니다. |
| **무료 hosted service** | [mu0.app](https://mu0.app)은 배포·Web 접근·선택적 공유 링크를 위한 것으로, 라이브러리를 맡지 않습니다. |
