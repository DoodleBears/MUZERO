Agent DJ는 LLM을 라이브러리의 사서·큐레이터·음악 생성 오케스트레이터로 바꿉니다. MUZERO를 보조 모니터에 띄워두면 코딩·디자인·글쓰기·긴 집중 세션 동안 라디오처럼 작동합니다.

## 할 수 있는 일

- **검색과 큐레이션** — Agent가 라이브러리를 검색하고, 태그와 메모를 맥락으로 사용해 세트를 만들거나 이어갑니다.
- **신청 받기** — 분위기를 알려주고 seed 세트를 주면, 플레이어를 지켜보지 않아도 큐를 이어갑니다.
- **생성** — 완전히 새로운 곡이 필요할 때, DJ가 `TrackBrief`(caption, 가사, style, BPM, key, structure, 생성 힌트)를 작성해 음악 생성 provider에 넘깁니다.

## Provider

음악 생성은 교체 가능합니다:

- **Mock** — 오프라인 자리표시 provider(기본). 네트워크나 key 없이도 루프가 동작합니다.
- **Cloud(BYOK)** — 사용자가 설정하는 실제 생성 API. DJ는 특정 vendor에 직접 말하지 않고, adapter가 brief를 번역하므로 라이브러리가 한 곳에 묶이지 않습니다.

## BYOK

LLM과 음악 생성 API key는 **직접 가져오는 키**입니다: 설정에서 입력하고 기기에만 저장됩니다. MUZERO는 서버 측 key를 보유하지 않으며, 사용자가 설정한 제3자 API 외에는 아웃바운드 요청을 하지 않습니다.

> key는 앱 bundle, 커밋된 `.env`, URL, 로그, 텔레메트리에 절대 기록되지 않습니다.
