MUZERO는 호스팅되는 **웹 앱**과 **데스크톱 앱**(Electron)으로 실행됩니다. 라이브러리는 기기 로컬 데이터베이스에 저장됩니다 — 계정도, MUZERO 미디어 백엔드도 없습니다.

## 앱 열기

- **웹** — [my.mu0.app](https://my.mu0.app)을 열고 바로 업로드를 시작하세요.
- **데스크톱** — [다운로드 페이지](/ko/download/)에서 설치 파일을 받으세요. 데스크톱 앱은 온라인 소스 지원이 가장 좋습니다(일부 소스가 요구하는 요청 헤더를 설정할 수 있습니다).

웹과 데스크톱 앱은 각각 별도의 로컬 라이브러리를 가집니다(서로 다른 origin). [클라우드 동기화](/ko/docs/sync/)로 하나의 라이브러리를 공유하세요.

## 첫 5분

1. **음악 추가.** 오디오 파일, 폴더, MV를 드래그하거나 링크를 붙여넣으세요([소스](/ko/docs/sources/) 참고).
2. **메모 달기.** 태그, 메모, 추억 사진, 커스텀 커버를 더하세요. "음악은 추억을 담는다"가 핵심입니다.
3. **검색.** `⌘F` / `Ctrl+F`로 제목·아티스트·태그·가사·메모·온라인 소스를 통합 검색.
4. **세트 만들기.** 곡을 세트(재생목록)로 묶으세요. 업로드와 AI 생성 곡을 섞을 수 있습니다.
5. **DJ에게 맡기기**(선택). 모델을 연결해 [Agent DJ](/ko/docs/agent-dj/)가 큐를 이어가게 하세요.

## 키보드 우선

MUZERO는 대규모 로컬 라이브러리와 키보드 조작을 위해 설계되었습니다:

- 재생·큐·검색·내비게이션·라이브러리 작업의 단축키를 커스터마이즈.
- `⌘F` / `Ctrl+F`로 어디서나 전역 검색.
- 6,000곡 라이브러리도 수십 초 기다리지 않고 바로 사용할 수 있어야 합니다.
