MUZERO는 음악을 세 곳에서 모읍니다: 업로드한 파일, 검색한 온라인 소스, AI DJ가 생성한 곡. 모두 같은 로컬 라이브러리에 들어옵니다.

## 자신의 것을 업로드

- **오디오 파일, 폴더 전체, MV**를 가져오면 혼합 세트에 들어갑니다(하나의 세트에 오디오와 영상 공존 가능).
- 어떤 곡에든 **메모·태그·추억 사진·커스텀 커버**를 추가하세요.
- 제목·아티스트·앨범·태그·메모·가사·음역·소스 메타데이터로 검색합니다.
- 아티스트·앨범·세트·추억·가사·재생 기록을 같은 로컬 라이브러리에서 다룹니다.

미디어 bytes는 content-addressed 방식으로 저장되어 가벼운 track 행과 분리되므로, 큰 라이브러리도 빠르고 검색 가능합니다.

## 온라인 소스(데스크톱)

다음 소스의 스트림을 검색·해석합니다:

- **NetEase Cloud Music**
- **Bilibili**
- **YouTube**

팁:

- `⌘F` 검색에 링크 — 또는 **BV 번호 / 영상 ID / 재생목록 링크** — 를 붙여넣으면 키워드 검색 대신 바로 해석합니다.
- 소스가 요구하면 **로컬 로그인**으로 더 높은 음질이나 계정 전용 콘텐츠를 사용할 수 있습니다. 로그인은 기기에 저장됩니다([BYOK](/ko/docs/agent-dj/#byok)).
- 스트리밍 곡과 커버를 **로컬에 캐시**해 오프라인 재생할 수 있습니다.
- 데스크톱에서는 Bilibili / YouTube 영상을 재생 가능한 로컬 트랙으로 **다운로드**(화질 선택)하거나, 보관함 / 재생목록 전체를 세트로 가져올 수 있습니다.

> 온라인 소스는 **데스크톱 앱**에서 가장 잘 동작합니다 — 일부 소스가 요구하는 커스텀 요청 헤더를 보낼 수 있습니다. 웹 빌드는 CORS의 제약을 받을 수 있습니다.
