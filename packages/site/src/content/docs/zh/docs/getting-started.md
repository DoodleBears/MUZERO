MUZERO 提供托管的 **Web 版**和 **桌面版**（Electron）。你的曲库存在设备本地的数据库里——没有账号，也没有 MUZERO 媒体后端。

## 打开 app

- **Web** —— 打开 [my.mu0.app](https://my.mu0.app) 直接开始上传。
- **桌面版** —— 从[下载页](/zh/download/)获取安装包。桌面版对在线音乐源支持最好（它能设置某些源所需的请求头）。

Web 版和桌面版各自保存独立的本地曲库（它们是不同的 origin）。用[云同步](/zh/docs/sync/)让它们共用同一个曲库。

## 头五分钟

1. **加音乐。** 拖入音频文件、文件夹或 MV——或粘贴一个链接（见[音乐源](/zh/docs/sources/)）。
2. **加注释。** 给曲目打标签、写备注、放记忆照片或自定义封面。「音乐承载回忆」就是核心。
3. **搜索。** 按 `⌘F` / `Ctrl+F` 全局搜索标题、艺人、标签、歌词、备注和在线来源。
4. **建歌单。** 把曲目组成一个集（歌单）。一个集可以混合你的上传和 AI 生成的曲目。
5. **让 DJ 接管**（可选）。接入一个模型，让 [Agent DJ](/zh/docs/agent-dj/) 持续把队列接上。

## 键盘优先

MUZERO 为本地大曲库和键盘操作而设计：

- 自定义播放、队列、搜索、导航、曲库管理的快捷键。
- `⌘F` / `Ctrl+F` 在任何地方打开全局搜索。
- 一个 6000 首歌的曲库应该立刻可用，而不是先卡几十秒。
