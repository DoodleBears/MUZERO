MUZERO 把你的音乐从三处汇到一起：你上传的文件、你搜索的在线来源、以及 AI DJ 生成的曲目。所有内容都落进同一个本地曲库。

## 上传你自己的

- 拖入**音频文件、整个文件夹或 MV**——它们进入混合集（一个集可以同时有音频和视频）。
- 给任意曲目加**备注、标签、记忆照片和自定义封面**。
- 按标题、艺人、专辑、标签、备注、歌词、转写和来源元数据搜索。
- 在同一个本地曲库里浏览艺人、专辑、集、记忆、歌词和播放历史。

媒体字节以内容寻址方式保存，独立于轻量的曲目行，所以大曲库仍然又快又可搜。

## 在线来源（桌面端）

搜索并解析以下来源的流：

- **网易云音乐**
- **Bilibili**
- **YouTube**

提示：

- 在 `⌘F` 搜索里粘贴链接——或只输入 **BV 号 / 视频 ID / 歌单链接**——MUZERO 会直接定位解析，而不是按关键词搜索。
- 在来源要求时**本地登录**可解锁更高音质或账号内容。登录态保存在你的设备上（[BYOK](/zh/docs/agent-dj/#byok)）。
- 在线曲目和封面会**缓存到本地**离线播放。
- 桌面端可以把 Bilibili / YouTube 视频**下载**为可播放的本地曲目（可选清晰度），或把整个收藏夹 / 歌单导入为一个集。

> 在线来源在**桌面版**体验最好——它能发送某些源所需的自定义请求头。Web 版可能受 CORS 限制。
