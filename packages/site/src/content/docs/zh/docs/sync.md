MUZERO 从不托管你的曲库。云同步指向**你自己配置和拥有的存储**，所以你能让每台设备同处一个曲库，而不必把媒体交给任何人。

## 工作方式

1. 在设置里**配置一次云盘**（当前路径是 Cloudflare R2 / S3 兼容对象存储）。
2. MUZERO 把曲库**发布**到该存储，并**拉取**更新。
3. 复制一个可信的**设置链接**，快速把另一台手机或电脑接入同一个曲库。

会同步的内容：集、曲目、封面、备注、记忆、歌词和播放元数据——都在你自己的设备之间，中间没有 MUZERO 服务器。

## 存储后端

- **当前**：Cloudflare R2 / S3 兼容对象存储。
- **路线**：面向 Nextcloud、Synology、rclone serve 等私人云的 WebDAV 支持。

媒体字节以内容寻址保存，所以重新同步只搬运变化的部分。

## 分享给朋友

- 用只读曲库 / 分享链接把音乐发给朋友。
- 更完整的 `mu0.app` 短链和可撤销邀请在路线里。即便如此，**曲目字节仍来自你配置的存储或设备**——只有分享链接和权限元数据涉及 `mu0` 服务。

## 凭据只在本地

存储凭据只保存在你的设备上（BYOK）。它们从不写进应用 bundle、提交的 `.env`、URL、日志或遥测。
