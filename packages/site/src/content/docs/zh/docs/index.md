MUZERO 是一个**本地优先的音乐和视频播放器**，为「歌曲也是回忆」的人而做。它把私人曲库、散落各处的在线来源、视觉化播放、自有云盘同步，以及一位 LLM 驱动的 DJ，放进同一个应用。

## 四个体验，一个曲库

- **私人音乐博物馆** —— 上传音频和 MV，为每首歌写备注、打标签、放封面照片，回到它属于的那段时间。
- **多源入口** —— 在桌面端搜索和播放网易云音乐、Bilibili、YouTube，并把这些曲目纳入 MUZERO。
- **视觉播放器** —— 受 Poweramp 启发的播放界面、封面取色、动态背景与音频可视化。
- **Agent DJ** —— 接入模型，让它搜索曲库、整理歌单、接受点歌，或生成下一首歌。

## 我们的承诺

| 原则 | 含义 |
|------|------|
| **本地优先** | 曲目、歌单、备注、标签、封面、设置、播放统计都在设备本地数据库 `muzero-db`。 |
| **不托管你的媒体** | MUZERO 从不保存你的曲库。云同步指向你自己配置和拥有的存储。 |
| **BYOK** | LLM key、音乐生成 key、源登录态、云盘凭据都只保存在你的设备上。 |
| **免费 hosted service** | [mu0.app](https://mu0.app) 用于分发、Web 访问和可选的分享链接——不接管你的曲库。 |
